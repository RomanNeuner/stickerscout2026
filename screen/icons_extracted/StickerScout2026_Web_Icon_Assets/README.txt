StickerScout 2026 - Web Icon Assets

Quelle / Stilbasis: Lucide Icons / Open-Source Icon-Stil. Die Icons wurden als saubere SVG-Vektorassets fuer StickerScout 2026 aufbereitet und in den App-Farben exportiert.

Farben:
- gold: #F0A500
- white: #FFFFFF
- grey: #A8B0AC
- dark: #0D1F1A

Enthaltene Symbole:
- arrow-left: Pfeil nach links
- question-mark-circle: Fragezeichen/Hilfe
- camera: Kamera
- flash-zap: Blitz
- gallery-image: Galerie/Bild
- home: Home
- scan: Scannen
- album-book: Album
- calendar: Spielplan
- profile-user: Profil
- crown-pro: Krone/Pro
- shutter-circle: Ausloeser
- barcode-number: Barcode/Nummer

Empfehlung fuer App-Implementierung:
- React Native: SVGs mit react-native-svg verwenden oder in Icon-Komponente umwandeln.
- Android/iOS Asset-Nutzung: PNG 1024 als Master; fuer produktive Builds besser SVG/Vektor verwenden.
- Active Tab: gold; inactive Tab: grey oder white mit reduzierter Deckkraft.
